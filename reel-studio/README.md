# استودیو ریل: ایجنت ساخت ویدیوی اینستاگرام

ایجنت روی n8n سرور (`panel.sairox.ir`) اجرا می‌شود و با سایروکس/AICOS هیچ ارتباطی ندارد. جدول‌هایش در schema جداگانه‌ی `reel` است.

## اجزا

| بخش | کار |
|---|---|
| `REEL_00_DB_Setup` | جدول‌ها، تابع `reel.api` پنل، و بارگذاری صفحه‌ی پنل از همین ریپو. اجرای دوباره بی‌خطر است و پنل را به‌روز می‌کند. |
| `REEL_01_Director` | سناریو برای فیلم‌برداری: هوک، متن صحبت، اینکه هر جمله با چه تصویری گرفته شود، دعوت به اقدام، کپشن. |
| `REEL_04_Editor` | تدوین فیلم خود شما: آماده‌سازی ویدیو، تبدیل گفتار به متن با زمان هر کلمه، برنامه‌ی برش و موشن‌گرافی با هوش مصنوعی، رندر نهایی. |
| `REEL_03_Panel` | صفحه‌ی پنل در `/webhook/reel-studio` و API آن. |
| `render-service/` | سرویس Docker: آپلود مستقیم ویدیوهای بزرگ، آماده‌سازی با ffmpeg (عمودی، ۳۰ فریم، صدای نرمال‌شده)، تبدیل گفتار به متن، رندر با Remotion. |

ساخت ویدیو با هوش مصنوعی (کلیپ‌های Kling/Veo) حذف شد؛ ورک‌فلوی `REEL_02_Producer` آرشیو شده است.

## تدوین فیلم خودم: چه کار می‌کند

1. فایل‌های ویدیو (یک یا چند کلیپ) از پنل مستقیم به سرور رندر آپلود می‌شوند.
2. هر کلیپ عمودی و ۳۰ فریم می‌شود و صدایش نرمال می‌شود؛ گفتار با ElevenLabs Scribe به متن با زمان دقیق هر کلمه تبدیل می‌شود.
3. هوش مصنوعی متن را می‌خواند و تصمیم می‌گیرد چه بماند: تکرارها، جمله‌های نیمه‌کاره، «اِ… اُم…» و مقدمه‌ی طولانی حذف می‌شود و بهترین جمله می‌تواند اول ویدیو بیاید.
4. مکث‌های بیشتر از ۰٫۳۵ ثانیه بریده می‌شوند و بین برش‌ها زوم یک‌درمیان می‌خورد تا کات‌ها حرفه‌ای دیده شوند.
5. موشن‌گرافی روی همان لحظه‌ای که کلمه گفته می‌شود: کارت هوک، برچسب، زیرنویس معرفی، شمارنده‌ی عدد، چک‌لیست، مقایسه‌ی اشتباه/درست، استیکر، کلمه‌ی تأکیدی، عکس محصول. به‌علاوه‌ی قاب برند، لوگو، نوار پیشرفت، موزیک و کارت دعوت به اقدام.
6. ویدیوی کلیپ افقی با پس‌زمینه‌ی تار عمودی می‌شود. خروجی حداکثر ۱۸۰ ثانیه است.

## هزینه

برای هر ویدیو حدود ۰٫۰۳ تا ۰٫۰۸ دلار: تبدیل گفتار به متن (چند سنت برای ۳ دقیقه) و یک بار برنامه‌ریزی تدوین با هوش مصنوعی. رندر روی سرور خودتان رایگان است.

## راه‌اندازی سرویس رندر (یک بار)

سرور پیشنهادی: حداقل ۴ هسته و ۸ گیگ رم. رندر یک ریل ۳۰ ثانیه‌ای حدود ۱ تا ۳ دقیقه طول می‌کشد.

```bash
git clone -b claude/vibrant-bohr-9kghlj https://github.com/reza-frontend/full-project.git
cd full-project/reel-studio/render-service
cp .env.example .env
# در .env:
#   REEL_RENDER_API_KEY = مقدار render_key در جدول reel.settings
#   OPENROUTER_API_KEY  = همان کلید OpenRouter
#   REEL_PUBLIC_URL     = آدرس عمومی همین سرویس (مثلاً https://reels.sairox.ir)
docker compose up -d --build
curl http://localhost:3900/health
```

روی سرور سایروکس، سرویس رندر پشت همان Caddy که n8n را سرو می‌کند و زیر مسیر `https://panel.sairox.ir/reels` قرار گرفته است:

- `docker-compose.override.yml` کانتینر را به شبکه‌ی `sairox_default` وصل می‌کند.
- در `/opt/sairox/Caddyfile`، داخل بلوک `{$PANEL_DOMAIN}`:
  ```
  handle_path /reels/* {
      reverse_proxy reel-render:3900
  }
  ```
- در `.env`: `REEL_PUBLIC_URL=https://panel.sairox.ir/reels`

در تنظیمات پنل، «آدرس سرویس رندر» = `https://panel.sairox.ir/reels`.

## استفاده

1. `https://panel.sairox.ir/webhook/reel-studio` را باز کنید و با `panel_key` (در `reel.settings`) وارد شوید.
2. در «سبک برند» کسب‌وکار، مخاطب، رنگ، قاب، لوگو، موزیک و عکس محصولات را وارد کنید.
3. در «ساخت ویدیو» فیلم‌ها را آپلود کنید؛ ویدیوی تدوین‌شده در «ویدیوها» آماده‌ی بازبینی می‌شود. اگر برشی را دوست نداشتید، بازخورد بنویسید و «تدوین دوباره» بزنید (این بار تبدیل گفتار به متن تکرار نمی‌شود).
