# استودیو ریل: ایجنت ساخت ویدیوی اینستاگرام

ایجنت روی n8n سرور (`panel.sairox.ir`) اجرا می‌شود و با سایروکس/AICOS هیچ ارتباطی ندارد. جدول‌هایش در schema جداگانه‌ی `reel` است.

## اجزا

| بخش | کار |
|---|---|
| `REEL_00_DB_Setup` | ساخت جدول‌ها، تابع `reel.api` پنل، و بارگذاری صفحه‌ی پنل از همین ریپو. اجرای دوباره بی‌خطر است و پنل را به‌روز می‌کند. |
| `REEL_01_Director` | نوشتن سناریو در دو مرحله: نویسنده و ویراستار. هوک، صحنه‌ها، متن گوینده، پرامپت تصویر، دعوت به اقدام، کپشن و هشتگ را می‌سازد و امتیاز کیفیت می‌دهد. |
| `REEL_02_Producer` | صدای گوینده (ElevenLabs) و کلیپ هر صحنه (Kling یا Veo از طریق OpenRouter) را می‌سازد، منتظر آماده شدن کلیپ‌ها می‌ماند، رندر نهایی را انجام می‌دهد و ویدیو را برای بازبینی آماده می‌کند. |
| `REEL_03_Panel` | صفحه‌ی پنل در `/webhook/reel-studio`، API پنل، و ساخت خودکار روزانه ساعت ۹ صبح به وقت تهران. |
| `render-service/` | سرویس رندر Remotion داخل Docker. ویدیوی ۱۰۸۰×۱۹۲۰ با زیرنویس فارسی کلمه‌به‌کلمه، کارت هوک، برچسب صحنه، کارت دعوت به اقدام، لوگو، نوار پیشرفت و موزیک می‌سازد. |

## حالت‌ها

- **خودکار**: ایجنت از اطلاعات کسب‌وکار و علایق، موضوع را خودش انتخاب می‌کند و تکراری نمی‌نویسد.
- **موضوع**: شما ایده می‌دهید، ایجنت ریل کامل را می‌نویسد.
- **سناریوی کامل**: متن شما عیناً گفته می‌شود و ایجنت فقط صحنه، تصویر و زیرنویس را می‌سازد.

هر ویدیو اول به‌صورت سناریو نمایش داده می‌شود. نوشتن سناریو ارزان است و ساخت ویدیو هزینه دارد. می‌توانید متن را ویرایش کنید، با بازخورد سناریوی تازه بگیرید یا تأیید کنید تا ساخته شود. بازخوردها و ویدیوهای تأییدشده یا ردشده، ورودی سناریوهای بعدی همان برند می‌شوند.

## راه‌اندازی سرویس رندر (یک بار)

سرور پیشنهادی: حداقل ۴ هسته و ۸ گیگ رم. رندر یک ریل ۳۰ ثانیه‌ای حدود ۱ تا ۳ دقیقه طول می‌کشد.

```bash
git clone -b claude/vibrant-bohr-9kghlj https://github.com/reza-frontend/full-project.git
cd full-project/reel-studio/render-service
cp .env.example .env
# در .env:
#   REEL_RENDER_API_KEY = مقدار render_key در جدول reel.settings
#   OPENROUTER_API_KEY  = همان کلید OpenRouter
#   REEL_PUBLIC_URL     = آدرس عمومی همین سرویس (مثلاً https://reels.sairox.ir)
docker compose up -d --build
curl http://localhost:3900/health
```

یک زیردامنه (مثلاً `reels.sairox.ir`) را از طریق reverse proxy به پورت 3900 وصل کنید. آدرس باید از اینترنت باز شود، چون OpenRouter عکس‌های برند را از همین آدرس می‌خواند و پنل ویدیوها را از آن پخش می‌کند.

بعد در پنل، بخش «تنظیمات»، همین آدرس را در «آدرس سرویس رندر» بگذارید.

## استفاده

1. `https://panel.sairox.ir/webhook/reel-studio` را باز کنید و با `panel_key` (در `reel.settings`) وارد شوید.
2. در «سبک برند» کسب‌وکار، مخاطب، علایق، رنگ، لوگو، صدا و **عکس‌های واقعی محصول** را وارد کنید. ایجنت این عکس‌ها را متحرک می‌کند تا ویدیو، کسب‌وکار واقعی شما را نشان دهد.
3. در «ساخت ویدیو» حالت را انتخاب کنید، سناریو را بررسی و تأیید کنید و ویدیوی آماده را با کپشن دانلود کنید.

## هزینه (تقریبی)

- سناریو: چند سنت
- صدا: کمتر از ۰٫۰۵ دلار
- کلیپ‌ها: کیفیت استاندارد (Kling 3، ۷۲۰p) حدود ۰٫۰۸۴ دلار برای هر ثانیه، یعنی برای ریل ۳۰ ثانیه‌ای حدود ۲٫۵ تا ۳ دلار. کیفیت پرمیوم (Veo 3.1 Fast، ۱۰۸۰p) حدود ۰٫۱ دلار برای هر ثانیه.
- سقف هزینه‌ی هر ویدیو در تنظیمات است (پیش‌فرض ۶ دلار). اگر برآورد هزینه از سقف بیشتر شود، ویدیو ساخته نمی‌شود.
